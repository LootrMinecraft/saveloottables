## Save Loot Tables

Save Loot Tables is a multi-platform mod for Minecraft 1.21 for the NeoForge and Fabric mod loaders.

Incorrect item names can prevent an entire loot table from being loaded.

This mod prevents Vanilla from discarding the remaining valid entries when loot tables with an invalid or incorrect item name in them are loaded.

### Notes

This mod is only required server side.

Please note: mods that display loot on the client-side may not display correctly without Save Loot Tables installed.
